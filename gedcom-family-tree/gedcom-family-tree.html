GEDCOM Family Tree

Open a GEDCOM file and see the whole thing at once — every individual, every family, every disconnected branch — laid out by generation. Alongside the tree you get a report on how the file measures up against the GEDCOM 5.5.1 specification: broken links, dates that are not dates, tags in places the specification does not allow.

Nothing is uploaded

The file is read in the page with the browser's own file reader. There is no server, no account, and no network request — you can open this page offline and it still works.

The whole graph, not one branch

A family file is a graph: people remarry, cousins marry, and most exports hold several unconnected families. Everyone is placed, once, on a generation grid.

Validated against 5.5.1

Grammar, cross-references, date values, record structure and internal consistency, each finding grouped with a count, an explanation and sample line numbers.

Part of a small collection of single-file browser tools. GEDCOM 5.5.1 is the lineage-linked file format published by The Church of Jesus Christ of Latter-day Saints in 1999.
